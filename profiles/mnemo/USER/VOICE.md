# VOICE.md — user-model writing fingerprint (derived)

> The **derived** layer of the user model: a measured fingerprint of the
> human's writing — sentence length, tell-frequency, signature moves —
> computed from their own writing (grants and papers' `## Verbatim`, any
> preserved prose). Not always loaded; consulted only when producing
> documents in the human's voice, never in conversation.
>
> The **judgment** half of writing voice (how an argument should be built)
> lives in the spine (`USER/<name>.md`, a "writing voice" section). This
> file holds only the **measurement**. Where a measured fact here conflicts
> with a generic default in `STYLE.md`, the measured fact wins — the corpus
> is the human's actual writing.
>
> Built by its own producer skill on demand; no schedule is wired, and no
> skill rewrites this file automatically.
